## 2025-05-15 - Reverse Tabnabbing Prevention via DOMPurify Hooks
**Vulnerability:** User-provided HTML content (such as EPUB chapters) may contain anchor links that, when clicked, open in the same window (interfering with Tauri app execution context) or open in a new window but retain a reference to `window.opener`, exposing the application to reverse tabnabbing attacks.
**Learning:** `DOMPurify` does not automatically add `rel="noopener noreferrer"` or `target="_blank"` to anchor tags during sanitation. We must use a `DOMPurify.addHook('afterSanitizeAttributes')` to ensure these attributes are applied to external links. Also, the config `ADD_ATTR: ['target', 'rel']` must be explicitly set, otherwise the newly added attributes will be stripped by DOMPurify.
**Prevention:** Whenever using `DOMPurify` to render untrusted HTML that may contain links, consider using an attribute hook to force safe external navigation (e.g., `rel="noopener noreferrer"` and `target="_blank"`), and update the sanitize config to allow those added attributes.
