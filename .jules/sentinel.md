## 2024-11-01 - SQL Injection Vulnerability in ProgressRepository
**Vulnerability:** Found a SQL injection vulnerability in `src-tauri/src/database/progress_repository.rs` where the `query_one` method dynamically constructs the SQL query string using `format!` and interpolates a `column` name without validation. This allows an attacker to inject arbitrary SQL logic if they can control the `column` argument.
**Learning:** The vulnerability existed because the developer attempted to reuse a single method (`query_one`) for queries filtering on different columns (`work_id` and `content_identity`). While the `value` is properly parameterized, the `column` name is interpolated directly into the query string.
**Prevention:** Avoid dynamic interpolation of column names using `format!`. If a method needs to support different column names, use a `match` statement allowlist to validate the input against a predefined set of allowed column names, or write separate query strings for each column.
