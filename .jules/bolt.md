## 2024-10-19 - Ensure child component memoization by passing stable callbacks using useRef for state
**Learning:** React.memo is ineffective when you pass an inline arrow function, or a function that is recreated on every render because its dependency array updates frequently. In lists or grids (like LibraryPage or DashboardPage), this leads to `N` child components re-rendering unnecessarily. Using `useCallback` isn't enough if the function relies on state that changes, as the callback identity will still change on state update.
**Action:** Use `React.memo` for list components. Ensure callbacks passed from parents are wrapped in `useCallback`. If those callbacks need access to state that updates without triggering a render dependency update in the callback (which would break memoization), keep the state in a `useRef` updated via an effect, and read the state from the ref inside the `useCallback`. This pattern maintains a stable callback signature. Also, design child component props to accept identifiers (`id`, `title`) so that the callback can act on them without needing to close over specific item data that changes on list mutation.
