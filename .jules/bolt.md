## 2024-01-01 - React.memo and stable callbacks for BookCard lists
**Learning:** The application renders large grids of `BookCard` components. Inline callbacks passed to `BookCard` in `LibraryPage` and `CollectionDetailsPage` were causing unnecessary re-renders of the entire grid whenever state (like filters or collection items) changed. Furthermore, callbacks relying on local component state (like `collection`) would recreate on every state update, breaking memoization.
**Action:** Use `React.memo` on list components like `BookCard`. Refactor their props to accept identifying arguments (e.g., `id`, `title`) so parent components don't need to close over loop variables. Use `useCallback` with stable dependencies in parents, and `useRef` to maintain a stable reference to frequently changing state if needed by the callback.
