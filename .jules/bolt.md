## 2024-10-24 - Memoizing list components with stable callbacks
**Learning:** In React, when memoizing components rendered in a list (like `BookCard` via `React.memo`), passing inline arrow functions from parent components ruins the memoization because new function references are created on every render. To fix this, parents must pass stable callbacks created with `useCallback`. However, closing over specific item data within `useCallback` inside a mapped array is an anti-pattern that can lead to stale closures.
**Action:** Refactor callback signatures to accept identifying arguments (e.g., `id`, `title`) from the child component. The child then calls these handlers passing the specific arguments. If the parent callback needs access to changing state without breaking its own stability, use `useRef` to hold the latest state and access `ref.current` inside the `useCallback`.
