## 2026-08-30 - Memoization of Virtualized/Grid Components and Stale Closures
**Learning:** When using `React.memo` on list items (like `BookCard` in a large library grid) to prevent unnecessary re-renders during parent state updates (such as changing a sort or deleting an item), it is essential to pass stable callback references from the parent using `useCallback`. Furthermore, if the parent's callback needs access to changing parent state (like the current collection object), adding that state to the `useCallback` dependency array defeats the memoization. The correct pattern is to use a `useRef` in the parent to hold the mutable state for the callback, while the callback itself expects identifying arguments (`id`, `title`) from the child, completely decoupling the child from the parent's closure and rendering cycles.
**Action:** Always verify that callbacks passed to `React.memo` components do not have unstable dependencies. Refactor component props to pass identifiers back up, and use `useRef` to break dependency chains in `useCallback` where necessary.
