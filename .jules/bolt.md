## 2024-05-18 - Stable Callbacks for React Memoization
**Learning:** In React list views rendering highly dynamic or complex item components, simply wrapping the item component in `React.memo` isn't enough. Inline callbacks created in the parent (e.g. `onAction={() => action(item.id)}`) break the memoization by providing a new callback reference every render, causing the item component to re-render anyway.
**Action:** When memoizing list components, refactor the item component's callback signatures to accept identifying data (like `id` or `title`) and use `useCallback` in the parent to pass stable function references down to each item. If the parent callback needs access to rapidly changing state, store that state in a `useRef` to avoid stale closures without breaking the callback's stability.
