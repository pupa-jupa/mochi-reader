## 2023-10-27 - Stable Callbacks in Memoized List Components
**Learning:** In the React frontend, when using `React.memo` for list components (like `BookCard`), passing inline functions from the parent for event handlers causes unnecessary re-renders of all items when the parent state changes. Trying to fix this by using `useCallback` on a function that directly accesses the parent state causes stale closures unless that state is in the dependency array (which defeats the purpose as it changes frequently).
**Action:** Always refactor callbacks to accept an identifying argument (e.g., `id`, `title`) from the child component instead of closing over item-specific data in the parent's loop. For parent components that need to read changing state without causing their `useCallback` to update, use a `useRef` updated via `useEffect` to maintain a stable reference to the data, and read from `.current` inside the `useCallback`.
