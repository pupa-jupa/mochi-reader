## 2024-03-24 - React.memo with Inline Callbacks
**Learning:** When optimizing React lists (like `BookCard` inside `LibraryPage`), using `React.memo` with a custom comparison function that ignores callback props can lead to critical stale closure bugs. Callbacks must be included in the comparison if they are not stable, or alternatively, parent components must provide stable callbacks (e.g. via `useCallback`).
**Action:** Always include callback props in `React.memo` equality checks unless they are guaranteed to be completely free of closure dependencies. In this codebase, since parent components recreate inline callbacks that access `work.id` or `store`, comparing those callbacks explicitly ensures safety. If `React.memo` needs to ignore callbacks for performance, the parent *must* use `useCallback` appropriately without lint warnings.
