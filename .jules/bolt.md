## 2023-10-09 - Memoizing list components and passing stable callbacks
**Learning:** When using `React.memo` on list item components (like `BookCard`), parent components must pass stable function references via `useCallback`. Otherwise, inline functions or new closures created on each parent render will defeat the memoization, causing all list items to re-render unnecessarily.
**Action:** Always wrap callback props in list components with `useCallback`. If the callback needs access to current state that might change (like the full collection object), use `useRef` to maintain a stable reference to that state inside the stable callback, avoiding both stale closures and placing async side effects inside pure state updaters. Additionally, refactor component props to accept identifying arguments (e.g., `id`) rather than relying on closures without arguments, to better support stable callback functions.
