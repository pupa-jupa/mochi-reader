## 2024-10-18 - Avoid Inline Callbacks with React.memo in Lists
**Learning:** In lists of components, simply wrapping the child component with `React.memo` isn't enough to prevent re-renders if parent components pass inline closure callbacks (like `onRemove={() => remove(item.id)}`). This is an anti-pattern that defeats memoization because a new function reference is created every render, causing all items in the list to re-render.
**Action:** Always refactor callback signatures on memoized list child components to accept identifying arguments (e.g., `id`, `title`). This allows parent components to define stable event handlers using `useCallback` that do not need to capture map-specific item variables in scope, maximizing the benefit of `React.memo` and preventing full list re-renders.
