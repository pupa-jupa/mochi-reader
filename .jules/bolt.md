## 2024-05-08 - Memoizing List Components with Stable Callbacks
**Learning:** Using `React.memo` on list items (like `BookCard`) is ineffective if the parent component passes new inline closures as callback props on every render. This leads to unnecessary re-renders of the list items or creates stale closures if a custom equality function ignores the callbacks.
**Action:** When creating list components, design the callback props to accept identifying arguments (e.g., `id`, `title`) from the child component. In the parent component, wrap the callback handlers in `useCallback` to maintain referential equality, ensuring `React.memo` successfully prevents re-renders. Use refs (e.g., `useRef`) in the parent to access the latest state within the stable callback if needed without updating its dependencies.
