## 2023-10-28 - React.memo and Stable Callbacks for List Virtualization/Rendering
**Learning:** Using `React.memo` with custom comparison functions that ignore inline callbacks, or passing inline callbacks (e.g. `onClick={() => action(id)}`) to memoized components, is an anti-pattern. This causes the component to either re-render unnecessarily or use stale closures.
**Action:** When rendering lists of items, ensure the child component (e.g. `BookCard`) is wrapped in `React.memo`, and its callbacks accept identifiers (like `id` or `title`) instead of specific item data. Use `useCallback` in the parent to create a single, stable callback function to pass down to all children. When a parent needs to access rapidly changing state inside a stable `useCallback`, use `useRef` to hold the latest state reference rather than adding the state to the dependency array.
