## 2024-11-02 - React Memo and Stable Callbacks
**Learning:** Using `React.memo` with list components (like `BookCard`) only prevents re-renders if parent components pass stable callback references. Inline callbacks (e.g., `onClick={() => onRemove(work.id)}`) recreate functions every render, breaking memoization. Also, maintaining a stable reference to dynamic state (like a `collection` list) with `useRef` inside a `useCallback` is an effective way to avoid stale closures without breaking the callback's stability.
**Action:** Always wrap callbacks for memoized list children in `useCallback`. Refactor component props to accept identifiers (`id`, `title`) so the child can pass them back, avoiding the need for the parent to create a new closure for each item just to capture its `id`.
