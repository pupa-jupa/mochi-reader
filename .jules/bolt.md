## 2024-10-27 - React.memo on Frequently Rendered List Components
**Learning:** In lists with numerous items (like `LibraryPage` potentially showing 80 items), individual item updates (like reading progress changes or favorite toggles) or generic state changes might re-render all items if the components aren't memoized. Because parent components often pass inline functions or callbacks that aren't perfectly stable, simple memoization isn't enough; a custom comparison function is needed to check if the essential props (like the `work` object) actually changed.
**Action:** When identifying list components rendered many times with complex props and callbacks (like `BookCard`), use `React.memo` with a custom comparison function focusing on the primary data object. Ensure the `work` object reference change correctly triggers a re-render.
