## 2024-03-22 - Optimize BookCard re-rendering
**Learning:** List items like `BookCard` will re-render unnecessarily on parent state changes (e.g., updating a collection or a library filter) if they receive inline arrow functions as props (`onRemove={() => ...}`). This forces React to re-render every item in a list even if only one changed. Furthermore, `React.memo` is completely ineffective if callbacks aren't stable.
**Action:** Always wrap repeating list components in `React.memo` and refactor their props to accept stable callbacks created via `useCallback`. To avoid stale closures in list item callbacks, design the component's callback props to receive identifying arguments (e.g., `id: string`) and use `useRef` to hold stable references to frequently changing state that the callbacks need to access.
