## 2024-05-24 - Missing Loading Spinners on Async Action Buttons\n**Learning:** Found a pattern where asynchronous action buttons (like saving metadata, finding source files) lacked visual feedback (loading spinners) when disabled, making the UI feel unresponsive and leading to potential user confusion.\n**Action:** When implementing or reviewing async operations triggered by buttons, ensure the button replaces its icon with a `.spinner` element during the `busy` or `saving` state.
