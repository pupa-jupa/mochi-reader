# Приватность и безопасность

Mochi Reader — local-first приложение. Библиотека, прогресс, закладки, коллекции, настройки и история хранятся в локальной SQLite database. Аккаунт и обязательная телеметрия отсутствуют.

## Импортированные книги

- по умолчанию сохраняется путь к оригиналу, а не копия файла;
- удаление из библиотеки не удаляет оригинальный файл;
- HTML, FB2 и EPUB преобразуются в безопасный document: script, iframe, forms, event handlers и опасные URL удаляются;
- JavaScript из книги никогда не выполняется;
- пути и содержимое книг не попадают в диагностическую сводку.

## Онлайн-источники

Источник работает в ограниченном native HTTP client, а не во встроенной web-странице. Разрешены только явно объявленные HTTPS origins. Реализованы SSRF-защита, DNS pinning, запрет proxy, same-origin redirects, timeouts, rate limit, MIME и byte limits.

Mochi Reader не обходит CAPTCHA, DRM, paywall, авторизацию или технические ограничения сайта. Подключайте только источник и контент, к которым у вас есть разрешённый доступ.

## Логи

Логи локальные, размер одного файла ограничен 2 МБ, сохраняется до пяти файлов. Они не отправляются автоматически. Перед передачей лога третьему лицу пользователь должен просмотреть его содержимое.

## CSP и permissions

WebView использует restrictive Content Security Policy. Tauri capability ограничена main window и только необходимыми dialog, opener, logging, clipboard write и window-state permissions.
