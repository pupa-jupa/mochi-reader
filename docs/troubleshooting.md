# Диагностика

## Приложение не запускается

Установите Microsoft Edge WebView2 Runtime и актуальные Visual C++ Runtime. Для dev-сборки также нужны Rust MSVC toolchain и Microsoft C++ Build Tools.

## Файл не найден

Откройте карточку произведения и нажмите «Найти исходный файл». Mochi Reader проверит формат и обновит путь, сохранив ID, прогресс, закладки, историю и коллекции.

## Формат не поддерживается

Сверьтесь с таблицей в README. CBR распознаётся, но встроенный RAR decoder отсутствует; безопасный обходной путь — распаковать архив в папку изображений или пересобрать его как CBZ. MOBI/AZW3/DJVU не импортируются как читаемые форматы.

## Онлайн-источник не подключается

- URL должен быть HTTPS без query, fragment, логина и пароля;
- manifest должен находиться в `/.well-known/mochi-reader.json` и отвечать `application/json`;
- для обычного HTML используйте декларативный профиль;
- редиректы на другой домен и изображения с необъявленного CDN блокируются;
- страницы, требующие CAPTCHA/вход/paywall, намеренно не поддерживаются.

## Кэш занял много места

В «Настройки → Кэш онлайн-манги» выберите лимит и нажмите «Очистить временный кэш». Офлайн-главы остаются. Удаление источника удаляет и его кэш.

## Что приложить к сообщению об ошибке

В «Настройки → Диагностика» сначала нажмите «Скопировать диагностическую информацию». Если этого мало, откройте папку логов и приложите свежий `.log` после ручной проверки, что вы готовы поделиться его содержимым.
